CHAPITRE 1 — PRISE EN MAIN
═══════════════════════════════════════════════════════════════

1.1 Première connexion
──────────────────────
Après réception de votre email d'invitation, suivez ces étapes :

1. Cliquez sur le lien d'activation dans l'email (valable 48 heures)
2. Définissez votre mot de passe :
   - Minimum 10 caractères
   - Au moins 1 majuscule, 1 chiffre, 1 caractère spécial
   - Ne pas réutiliser les 5 derniers mots de passe
3. Configurez votre profil (nom, photo, fuseau horaire)
4. Activez l'authentification à deux facteurs (recommandé)

Navigateurs compatibles :
- Google Chrome version 110 ou supérieure
- Mozilla Firefox version 115 ou supérieure
- Microsoft Edge version 110 ou supérieure
- Safari version 16 ou supérieure (Mac uniquement)

1.2 Interface principale
─────────────────────────
L'interface TechVision est organisée en 4 zones principales :

Zone 1 — Barre de navigation (gauche)
Accès rapide à tous les modules : Tableau de bord, Projets, 
Documents, Rapports, Intégrations, Paramètres.

Zone 2 — En-tête (haut)
Barre de recherche globale, notifications, profil utilisateur, 
accès à l'aide contextuelle.

Zone 3 — Zone de travail (centre)
Affichage du contenu de la section sélectionnée.

Zone 4 — Panneau latéral (droite)
Informations contextuelles, filtres, actions rapides.

1.3 Raccourcis clavier
───────────────────────
Ctrl + K : Ouvrir la recherche globale
Ctrl + N : Créer un nouvel élément
Ctrl + S : Sauvegarder
Ctrl + Z : Annuler la dernière action
Ctrl + / : Afficher tous les raccourcis
F1 : Aide contextuelle

CHAPITRE 2 — GESTION DES DOCUMENTS
═══════════════════════════════════════════════════════════════

2.1 Importer des documents
───────────────────────────
Méthode 1 — Glisser-déposer
Faites glisser vos fichiers directement dans la zone de dépôt 
centrale ou dans un dossier spécifique.

Méthode 2 — Bouton d'import
Documents → "+ Nouveau document" → "Importer depuis l'ordinateur"

Méthode 3 — Import depuis le cloud
Documents → "+ Nouveau document" → Choisir la source :
- Google Drive
- OneDrive
- Dropbox
- SharePoint

Formats supportés : PDF, DOCX, XLSX, CSV, PNG, JPG, MP4, ZIP
Limites par plan :
- Starter : 20 Mo par fichier, 10 Go total
- Pro : 50 Mo par fichier, 100 Go total
- Business : 500 Mo par fichier, 1 To total
- Enterprise : 2 Go par fichier, stockage illimité

2.2 Organiser vos documents
─────────────────────────────
Création de dossiers :
Documents → Clic droit → "Nouveau dossier" → Nommer le dossier

Déplacer des documents :
Sélectionner le document → Glisser vers le dossier cible
Ou : Clic droit → "Déplacer vers" → Choisir la destination

Étiquettes et tags :
Chaque document peut recevoir jusqu'à 10 étiquettes personnalisées.
Utile pour filtrer et retrouver rapidement vos fichiers.

2.3 Partager des documents
───────────────────────────
Partage interne (avec des collègues) :
1. Cliquer sur le document → "Partager"
2. Saisir le nom ou email du collègue
3. Choisir le niveau d'accès : Lecture, Commentaire, Édition
4. Définir une date d'expiration si nécessaire
5. Cliquer sur "Envoyer l'invitation"

Partage externe (avec des personnes hors de l'organisation) :
Disponible uniquement sur les plans Pro, Business et Enterprise.
1. Cliquer sur le document → "Partager" → "Lien public"
2. Configurer les options : lecture seule, protection par mot de passe
3. Définir une date d'expiration (obligatoire pour la sécurité)
4. Copier et partager le lien généré

2.4 Exporter vos données
─────────────────────────
Export d'un document unique :
Document → "..." → "Exporter" → Choisir le format

Export de toutes vos données :
Paramètres → Mon compte → onglet "Données" → "Exporter mes données"
Formats disponibles : CSV, JSON, PDF
Délai de génération : 5 à 30 minutes selon le volume
Lien de téléchargement valable 48 heures

CHAPITRE 3 — GESTION DES UTILISATEURS (ADMINISTRATEURS)
═══════════════════════════════════════════════════════════════

3.1 Inviter des utilisateurs
──────────────────────────────
1. Admin → Utilisateurs → "+ Inviter des utilisateurs"
2. Saisir les adresses email (une par ligne ou séparées par virgules)
3. Choisir le rôle : Lecteur, Membre, Administrateur
4. Personnaliser le message d'invitation (optionnel)
5. Cliquer sur "Envoyer les invitations"

Rôles disponibles :
- Lecteur : consultation uniquement, pas de modification
- Membre : création et modification de ses propres contenus
- Gestionnaire : gestion des contenus de son équipe
- Administrateur : accès complet incluant facturation et sécurité

3.2 Gérer les permissions
──────────────────────────
Admin → Utilisateurs → Sélectionner un utilisateur → "Modifier"

Champs modifiables :
- Rôle et niveau d'accès
- Appartenance aux équipes
- Restrictions d'accès par projet
- Limites de stockage individuelles

3.3 Désactiver un compte
─────────────────────────
Admin → Utilisateurs → Sélectionner l'utilisateur → "Désactiver"

Important : la désactivation ne supprime pas les données de l'utilisateur.
Le compte peut être réactivé à tout moment.

Pour supprimer définitivement un compte et ses données :
Désactiver d'abord → Attendre 30 jours → "Supprimer définitivement"
Cette action est irréversible.

3.4 Authentification à deux facteurs (2FA)
──────────────────────────────────────────
Configuration individuelle (tous les plans) :
Profil → Sécurité → "Activer le 2FA" → Choisir la méthode

Configuration obligatoire pour toute l'organisation (Business+) :
Admin → Organisation → Sécurité → "2FA obligatoire" → Activer
Les utilisateurs disposent de 7 jours pour configurer leur 2FA.
Passé ce délai, ils seront bloqués jusqu'à configuration.

Méthodes disponibles :
1. Application TOTP (Google Authenticator, Authy) — recommandé
2. SMS (surcharge possible selon l'opérateur)
3. Email de vérification

3.5 Single Sign-On (SSO)
─────────────────────────
Disponible sur les plans Business et Enterprise uniquement.
Protocoles supportés : SAML 2.0, OAuth 2.0, OpenID Connect

Configuration :
Admin → Organisation → Sécurité → "Configurer le SSO"
Un guide de configuration détaillé est disponible pour :
- Azure Active Directory
- Google Workspace
- Okta
- Auth0

CHAPITRE 4 — TABLEAUX DE BORD ET RAPPORTS
═══════════════════════════════════════════════════════════════

4.1 Tableau de bord principal
───────────────────────────────
Le tableau de bord affiche en temps réel :
- Activité récente de votre équipe
- Documents modifiés récemment
- Tâches en attente
- Statistiques d'utilisation

Personnalisation :
Cliquer sur "Personnaliser" en haut à droite pour :
- Ajouter / supprimer des widgets
- Réorganiser les blocs par glisser-déposer
- Choisir la période d'affichage

4.2 Rapports prédéfinis
────────────────────────
Rapports → Bibliothèque de rapports

Rapports disponibles par défaut :
- Rapport d'activité utilisateurs (hebdomadaire/mensuel)
- Rapport d'utilisation du stockage
- Rapport d'accès et connexions
- Rapport d'activité par projet
- Rapport de partage de documents

4.3 Rapports personnalisés (Pro et supérieur)
───────────────────────────────────────────────
Rapports → "+ Nouveau rapport"

1. Choisir la source de données
2. Sélectionner les dimensions (date, utilisateur, projet, type de document...)
3. Choisir les métriques (nombre de vues, téléchargements, modifications...)
4. Appliquer des filtres
5. Choisir la visualisation (tableau, graphique, carte...)
6. Planifier l'envoi automatique par email

CHAPITRE 5 — INTÉGRATIONS
═══════════════════════════════════════════════════════════════

5.1 Intégrations disponibles
──────────────────────────────
Productivité :
- Slack : notifications et partage de documents
- Microsoft Teams : collaboration en temps réel
- Google Workspace : synchronisation Drive, Agenda, Gmail
- Microsoft 365 : synchronisation OneDrive, Outlook, Teams

CRM (Business et Enterprise) :
- Salesforce : synchronisation contacts et opportunités
- HubSpot : synchronisation contacts et deals
- Pipedrive : synchronisation pipeline commercial

ERP (Enterprise) :
- SAP : synchronisation données métier
- Oracle : synchronisation données financières

Automatisation :
- Zapier : automatisations sans code (toutes versions)
- Make (ex-Integromat) : automatisations avancées
- API REST : intégration sur mesure

5.2 Configurer une intégration
───────────────────────────────
Admin → Intégrations → Choisir l'intégration → "Connecter"

Étapes générales :
1. Autoriser TechVision à accéder à l'application tierce
2. Configurer les paramètres de synchronisation
3. Choisir la fréquence de synchronisation
4. Tester la connexion
5. Activer l'intégration

5.3 Gestion des clés API
─────────────────────────
Admin → API → "Générer une nouvelle clé"

Bonnes pratiques :
- Donner un nom explicite à chaque clé (ex: "Intégration Zapier Production")
- Définir une date d'expiration (90 jours recommandés)
- Ne jamais partager une clé API par email non chiffré
- Révoquer immédiatement une clé compromise

Limites par plan :
- Starter : 1 000 appels/jour
- Pro : 10 000 appels/jour
- Business : 100 000 appels/jour
- Enterprise : illimité

Versions API disponibles :
- v2 : standard, disponible tous les plans
- v3 : avancée avec webhooks, plans Business et Enterprise

CHAPITRE 6 — SÉCURITÉ ET CONFORMITÉ
═══════════════════════════════════════════════════════════════

6.1 Chiffrement des données
────────────────────────────
- Données en transit : TLS 1.3
- Données au repos : AES-256
- Sauvegardes : chiffrées AES-256, toutes les 4 heures
- Rétention des sauvegardes : 30 jours

6.2 Journaux d'audit
─────────────────────
Disponible sur tous les plans.
Admin → Sécurité → "Journaux d'audit"

Événements tracés :
- Connexions et déconnexions
- Modifications de documents
- Changements de permissions
- Actions administrateur
- Accès API
- Tentatives de connexion échouées

Rétention des journaux :
- Starter, Pro : 90 jours
- Business : 1 an
- Enterprise : 7 ans (conformité réglementaire)

6.3 Conformité réglementaire
─────────────────────────────
TechVision est conforme aux réglementations suivantes :
- RGPD (Règlement Général sur la Protection des Données)
- ISO 27001 (Sécurité de l'information)
- SOC 2 Type II
- HDS (Hébergement de Données de Santé) — Enterprise uniquement

DPA (Data Processing Agreement) disponible sur demande :
legal@techvision.fr

ANNEXE A — RÉSOLUTION DES PROBLÈMES COURANTS
═══════════════════════════════════════════════════════════════

Problème : Page blanche au chargement
Solution : Vider le cache navigateur (Ctrl+Shift+Del) → Actualiser

Problème : Upload de fichier échoue
Solution : 
1. Vérifier la taille du fichier vs limite de votre plan
2. Vérifier que le format est supporté
3. Essayer depuis un autre navigateur

Problème : Notifications non reçues
Solution :
1. Vérifier les paramètres de notification : Profil → Notifications
2. Vérifier que les emails TechVision ne sont pas en spam
3. Vérifier les paramètres de votre navigateur (autoriser les notifications)

Problème : Impossible de partager avec un utilisateur externe
Solution :
Le partage externe nécessite un plan Pro minimum.
Vérifier votre plan : Admin → Abonnement

Problème : Rapport ne se génère pas
Solution :
1. Vérifier la période sélectionnée (max 12 mois)
2. Vérifier que les données existent sur cette période
3. Contacter le support si le problème persiste
