Q1. Comment réinitialiser le mot de passe d'un client bloqué ?
──────────────────────────────────────────────────────────────
Procédure standard (compte non expiré) :
1. Accéder au portail admin : admin.techvision.fr/users
2. Rechercher le compte par email ou ID client
3. Cliquer sur "Actions" → "Réinitialiser le mot de passe"
4. Choisir "Envoyer un lien de réinitialisation par email"
5. Confirmer l'envoi — le client reçoit le lien sous 2 minutes

Si le compte est verrouillé après 5 tentatives échouées :
1. Même procédure jusqu'à l'étape 3
2. Cliquer sur "Déverrouiller le compte" avant la réinitialisation
3. Notifier le client par téléphone si l'accès est urgent

Délai de validité du lien : 24 heures
En cas d'échec : escalader au niveau 2 (ticket type : ACC-RESET)

Q2. Un client ne reçoit pas l'email de confirmation d'inscription ?
────────────────────────────────────────────────────────────────────
Causes possibles et solutions :

Cause 1 — Email en spam
→ Demander au client de vérifier le dossier spam/indésirables
→ L'expéditeur légitime est : noreply@techvision.fr

Cause 2 — Adresse email incorrecte lors de l'inscription
→ Vérifier dans le portail admin si l'adresse est correcte
→ Si incorrecte : corriger et renvoyer l'email de confirmation

Cause 3 — Domaine professionnel bloquant les emails externes
→ Demander au client de contacter son service IT
→ Whitelist à ajouter : techvision.fr, mail.techvision.fr

Cause 4 — Délai technique
→ Délai normal : 2 minutes maximum
→ Si > 10 minutes : renvoyer manuellement via admin → "Renvoyer confirmation"

Q3. Comment modifier l'adresse email principale d'un compte ?
──────────────────────────────────────────────────────────────
Uniquement possible par un agent support niveau 1 ou supérieur.

Procédure :
1. Vérifier l'identité du client (3 éléments : nom, prénom, date de naissance ou téléphone)
2. Admin → Compte client → "Modifier les informations"
3. Changer l'email → Sauvegarder
4. Un email de confirmation est envoyé aux DEUX adresses (ancienne et nouvelle)
5. Le client doit confirmer depuis la nouvelle adresse dans les 48h

Important : Ne jamais modifier l'email sans vérification d'identité préalable.

Q4. Que faire si un client signale un accès non autorisé à son compte ?
────────────────────────────────────────────────────────────────────────
Procédure urgence sécurité (à traiter en priorité absolue) :

1. Suspendre immédiatement le compte : Admin → "Suspendre le compte"
2. Réinitialiser le mot de passe
3. Révoquer toutes les sessions actives : Admin → "Déconnecter toutes les sessions"
4. Créer un ticket de sécurité : type SEC-BREACH
5. Escalader au niveau 2 ET notifier l'équipe sécurité : security@techvision.fr
6. Rappeler le client dans les 30 minutes pour confirmer les actions prises

Ne jamais laisser un compte potentiellement compromis actif.

Q5. Un client conteste une facture — quelle procédure suivre ?
───────────────────────────────────────────────────────────────
Étape 1 — Écoute et vérification
→ Récupérer le numéro de facture concernée
→ Vérifier dans Admin → Facturation → Historique des factures
→ Comparer avec le contrat client actif

Étape 2 — Cas d'une erreur confirmée de notre côté
→ Créer un avoir : Admin → Facturation → "Créer un avoir"
→ Montant maximum sans validation niveau 2 : 500 €
→ Au-delà de 500 € : escalader au responsable facturation
→ Délai de remboursement : 5 à 10 jours ouvrés

Étape 3 — Cas où la facture est correcte
→ Expliquer le détail de la facturation point par point
→ Envoyer le récapitulatif par email avec les justificatifs
→ Si le client maintient sa contestation : escalader niveau 2

Q6. Comment gérer une demande de résiliation d'abonnement ?
─────────────────────────────────────────────────────────────
Politique de résiliation TechVision :
- Préavis minimum : 30 jours
- Résiliation effective : fin du mois en cours + 30 jours
- Remboursement au prorata : non applicable (engagement mensuel)
- Remboursement au prorata annuel : applicable si > 6 mois restants

Procédure :
1. Tenter une rétention client (proposer une offre de fidélisation)
   → Réduction 20% pendant 3 mois (code : FIDELITE20)
   → Passage à un plan inférieur sans frais
2. Si le client maintient : Admin → Abonnements → "Planifier résiliation"
3. Envoyer la confirmation de résiliation par email
4. Créer un ticket type : RES-CONFIRM

Offres de rétention disponibles (validité : 72h) :
- Plan Starter → Gratuit 1 mois
- Plan Pro → -30% pendant 3 mois
- Plan Enterprise → Migration vers plan inférieur sans frais de migration

Q7. Un client souhaite changer de plan en cours de mois ?
──────────────────────────────────────────────────────────
Upgrade (passage à un plan supérieur) :
→ Effectif immédiatement
→ Facturation au prorata du mois en cours
→ Admin → Abonnements → "Changer de plan" → Sélectionner le nouveau plan

Downgrade (passage à un plan inférieur) :
→ Effectif à la prochaine date de renouvellement
→ Pas de remboursement pour le mois en cours
→ Vérifier que les données du client sont compatibles avec les limites du nouveau plan
→ Si dépassement de limites : avertir le client avant de procéder

Plans disponibles :
- Starter : 29€/mois — 5 utilisateurs, 10 Go stockage
- Pro : 79€/mois — 25 utilisateurs, 100 Go stockage
- Business : 199€/mois — 100 utilisateurs, 1 To stockage
- Enterprise : sur devis — illimité

Q8. Le client signale que l'application est lente ou inaccessible ?
────────────────────────────────────────────────────────────────────
Étape 1 — Vérifier le statut de la plateforme
→ Consulter : status.techvision.fr
→ Si incident en cours : informer le client et donner l'ETA de résolution
→ S'abonner aux notifications : status.techvision.fr/subscribe

Étape 2 — Si la plateforme est opérationnelle
→ Demander au client :
   - Navigateur utilisé (version ?)
   - Système d'exploitation
   - Connexion internet (filaire ou WiFi ?)
   - Le problème affecte-t-il tous les utilisateurs ou un seul ?

Étape 3 — Solutions de premier niveau
→ Vider le cache et les cookies du navigateur
→ Tester sur un autre navigateur (Chrome, Firefox, Edge)
→ Tester sur une autre connexion réseau
→ Désactiver les extensions de navigateur

Étape 4 — Si le problème persiste
→ Demander une capture d'écran ou un enregistrement
→ Relever l'heure exacte et la fréquence du problème
→ Escalader niveau 2 avec ticket type : TECH-PERF

Navigateurs supportés :
- Chrome 110+
- Firefox 115+
- Edge 110+
- Safari 16+ (macOS uniquement)
Non supporté : Internet Explorer (toutes versions)

Q9. Comment aider un client à exporter ses données ?
──────────────────────────────────────────────────────
Export disponible en libre-service (client autonome) :
→ Paramètres → Mon compte → "Exporter mes données"
→ Formats disponibles : CSV, JSON, PDF
→ Délai de génération : 5 à 30 minutes selon le volume
→ Lien de téléchargement valable 48 heures

Si le client ne trouve pas l'option :
→ Chemin exact : Menu haut droite → "Paramètres" → onglet "Données" → "Export"
→ Guide vidéo : aide.techvision.fr/export-donnees

Export volumineux (> 1 Go) :
→ Nécessite une demande via ticket : type DATA-EXPORT
→ Traité par l'équipe technique sous 48h ouvrées
→ Livraison par lien sécurisé (SFTP ou lien chiffré)

Q10. Un client signale une perte de données ?
──────────────────────────────────────────────
Procédure critique — à traiter en urgence :

1. Ne jamais minimiser le problème
2. Collecter les informations :
   - Quelles données sont concernées ?
   - Depuis quand ?
   - Des modifications ont-elles été faites récemment ?
3. Créer un ticket critique : type DATA-LOSS (priorité P1)
4. Escalader IMMÉDIATEMENT au niveau 2 et à l'équipe technique
5. Rassurer le client : "Nous avons des sauvegardes automatiques toutes les 4 heures"

Politique de sauvegarde TechVision :
- Sauvegarde automatique : toutes les 4 heures
- Rétention : 30 jours
- Restauration possible : sous 4 heures ouvrées

Q11. Niveaux de support et escalade
─────────────────────────────────────
Niveau 1 — Agent support standard
→ Tickets : questions générales, reset mot de passe, facturation simple
→ Délai de réponse cible : 2 heures (chat) / 4 heures (email)
→ Résolution cible : 80% des tickets sans escalade

Niveau 2 — Support spécialisé
→ Tickets : problèmes techniques complexes, litiges facturation > 500€
→ Délai de prise en charge : 1 heure après escalade
→ Résolution cible : sous 24 heures

Niveau 3 — Ingénierie
→ Tickets : bugs confirmés, perte de données, incidents sécurité
→ Délai de prise en charge : 30 minutes (P1) / 2 heures (P2)

Priorités tickets :
- P1 (Critique) : plateforme inaccessible, perte de données, faille sécurité
- P2 (Haute) : fonctionnalité majeure indisponible, > 10 utilisateurs impactés
- P3 (Normale) : problème isolé, contournement disponible
- P4 (Basse) : question générale, amélioration

Q12. Comment traiter un client mécontent ou agressif ?
────────────────────────────────────────────────────────
Règle fondamentale : rester professionnel en toutes circonstances.

Étape 1 — Écoute active
→ Laisser le client s'exprimer sans l'interrompre
→ Reformuler le problème pour montrer qu'on a compris
→ Valider les émotions : "Je comprends que cette situation est frustrante"

Étape 2 — Action concrète
→ Ne pas promettre ce qu'on ne peut pas tenir
→ Donner un délai précis et le respecter
→ Proposer une solution immédiate si possible

Étape 3 — Si le client devient irrespectueux
→ Avertissement poli : "Je souhaite vous aider mais j'ai besoin que notre échange reste respectueux"
→ Si cela continue : "Je vais devoir mettre fin à cet échange. Un superviseur vous recontactera."
→ Transférer au superviseur et documenter l'incident

Ne jamais :
→ Hausser le ton
→ Promettre des compensations non autorisées
→ Partager des informations confidentielles sous pression

Q13. Un client signale que son intégration API ne fonctionne plus ?
────────────────────────────────────────────────────────────────────
Causes fréquentes :

Cause 1 — Clé API expirée ou révoquée
→ Admin → Compte client → API → Vérifier le statut de la clé
→ Si expirée : générer une nouvelle clé et l'envoyer de façon sécurisée
→ Ne jamais envoyer de clé API par email non chiffré

Cause 2 — Changement de version API
→ Vérifier la version utilisée par le client (v1, v2, v3)
→ API v1 : deprecated depuis janvier 2026 — migration vers v2 obligatoire
→ Guide de migration : dev.techvision.fr/migration-v2

Cause 3 — Dépassement du quota
→ Admin → Compte client → API → Statistiques d'utilisation
→ Plan Starter : 1 000 appels/jour
→ Plan Pro : 10 000 appels/jour
→ Plan Business : 100 000 appels/jour
→ En cas de dépassement : upgrade ou achat de quota supplémentaire

Documentation API complète : dev.techvision.fr/docs
